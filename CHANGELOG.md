# Changelog

## 1.9.0 · 2026-11-23

- Added a persistent reading queue with manual ordering and bulk actions.
- Added complete profile backup export, validation, migration, merge, and replace restore.
- Added retention controls, storage estimates, and protected-item cleanup.
- Added reading activity statistics with local-day and streak calculations.
- Added feed health diagnostics, refresh intervals, exponential backoff, and foreground scheduling.
- Added nested OPML import/export with a preview of duplicates and invalid entries.
- Added selected/all highlight and note exports in JSON and Markdown.
- Added an icon-based collapsed navigation rail with counts and tag/saved-search flyouts.
- Added pure-white and OLED-black themes.
- Added contextual keyboard shortcut coaching and cancellable full-article loading.
- Expanded unit and Playwright browser coverage.

Firebase synchronization work is intentionally excluded from this release.
