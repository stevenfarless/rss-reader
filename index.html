PREFERENCES

Settings

When a feed cannot be loaded directly, the reader first tries the site's own WordPress API. With the proxy fallback on, it will also try a public feed-to-JSON service as a last resort — that service sees the feed address. It is off by default.

Preferences backup

Export or restore your settings as JSON.

Subscriptions and preferences use localStorage. Articles and reading state are cached in IndexedDB. This site has no account or backend of its own. Feed loading depends on each publisher's CORS policy; feeds that block cross-origin requests load through the site's own WordPress API or, if enabled, the proxy fallback.
